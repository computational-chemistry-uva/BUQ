# BUQ + PLUMED example: 2D alanine dipeptide (φ, ψ)

This folder contains a minimal example of **Bayesian Umbrella Quadrature (BUQ)**
used together with **PLUMED** and **GROMACS** to reconstruct the 2D free
energy surface of alanine dipeptide in the backbone torsions φ and ψ.

BUQ is used here as a **method**: it proposes new (φ, ψ) points, runs biased
MD simulations using PLUMED, collects mean forces, and updates a
Gaussian‑process surrogate for the free energy.

PLUMED is used to:

- define the collective variables φ and ψ,
- apply moving harmonic restraints on their trigonometric projections
  (`sin_phi`, `cos_phi`, `sin_psi`, `cos_psi`) to handle periodicity,
- write COLVAR files that BUQ reads to estimate mean forces.

This example corresponds to the alanine dipeptide case study in the BUQ
paper:

- **Title:** Bayesian umbrella quadrature accelerates free-energy calculations across diverse molecular systems and processes  
- **Authors:** Eline K. Kempkes, Alberto Pérez de Alba Ortíz  
- **DOI:** https://doi.org/10.48550/arXiv.2601.08783

The main BUQ package and additional examples are in:

- https://github.com/computational-chemistry-uva/BUQ

## Relation to PLUMED

PLUMED input files are generated **on the fly** by the `Adipep` system
class (in `adipep_2d.py`). For each requested point
$$
 x = (\phi, \psi)
$$
BUQ calls `Adipep` methods that:

1. **Create PLUMED input**

   ```python
   def write_plumed_input(self, x: np.ndarray) -> None:
       """Create PLUMED input for CV point x = [phi, psi]."""
       phi, psi = x
       ...
       filename = f"plumed/plumed_{phi:.3f}_{psi:.3f}.dat"
       with open(filename, "w") as f:
           f.write("#vim:ft=plumed\n")
           f.write("MOLINFO STRUCTURE=simulations_essentials/diala.pdb\n")
           f.write("UNITS LENGTH=A TIME=ps ENERGY=kcal/mol\n")
           f.write("phi: TORSION ATOMS=@phi-2\n")
           f.write("psi: TORSION ATOMS=@psi-2\n")
           f.write("cos_phi: MATHEVAL arg=phi FUNC=cos(x) PERIODIC=NO\n")
           f.write("sin_phi: MATHEVAL arg=phi FUNC=sin(x) PERIODIC=NO\n")
           f.write("cos_psi: MATHEVAL arg=psi FUNC=cos(x) PERIODIC=NO\n")
           f.write("sin_psi: MATHEVAL arg=psi FUNC=sin(x) PERIODIC=NO\n")
           ...
           f.write(
               f"PRINT ARG=sin_phi,cos_phi,sin_psi,cos_psi,*.* "
               f"FILE=colvars/COLVAR_{phi:.3f}_{psi:.3f} STRIDE=100\n"
           )
   ```

   This defines φ/ψ torsions, constructs their trigonometric projections,
   adds `MOVINGRESTRAINT` blocks on those variables, and writes them to a
   COLVAR file:

   ```text
   colvars/COLVAR_{phi:.3f}_{psi:.3f}
   ```

2. **Run GROMACS + PLUMED**

   ```python
   def run_simulation(self, x: np.ndarray) -> None:
       """Called by BayesianQuadratureRunner: x = [phi, psi]."""
       phi, psi = x
       run_command("rm *#*")
       self.write_plumed_input(x)
       command = (
           "gmx mdrun -s simulations_essentials/md.tpr "
           + f"-plumed plumed/plumed_{phi:.3f}_{psi:.3f}.dat "
           + f"-nsteps {self.nsteps} "
           + f"-x traj/traj_{phi:.3f}_{psi:.3f}.xtc"
       )
       run_command(command)
       run_command("rm *#*")
       run_command("rm confout.gro ener.edr md.log state.cpt state_prev.cpt traj.trr")
   ```

   This runs a short biased MD simulation for the current `(φ, ψ)` window,
   writing the trajectory to `traj/traj_{phi:.3f}_{psi:.3f}.xtc`.

3. **Compute mean forces from COLVAR**

   ```python
   def get_force(self, x: np.ndarray) -> np.ndarray:
       """Return dF/dx for x = [phi, psi]."""
       phi_value, psi_value = x
       data = np.genfromtxt(f"colvars/COLVAR_{phi_value:.3f}_{psi_value:.3f}")
       data = data[data[:, 0] > self.measure_after_ps]
       # columns: sin_phi, cos_phi, sin_psi, cos_psi
       mean_vals = np.mean(data[:, 1:5], axis=0)
       sin_phi_real, cos_phi_real, sin_psi_real, cos_psi_real = mean_vals
       ...
       # return dF/dx (minus umbrella force)
       return np.array([-force_phi, -force_psi])
   ```

   The deviations between sampled and umbrella trigonometric values
   (multiplied by the force constants) give the mean forces, which BUQ
   then uses as observations.

In this PLUMED‑NEST egg we also **include a small set of PLUMED input and
COLVAR files** that were generated by running a short BUQ run, so users
can inspect or re‑run them without having to run the full BUQ workflow.

### Key files and folders

- `adipep_2d.py`  
  Defines the `Adipep` system class:

  - `__init__(...)`  
    sets bounds in φ/ψ, force constants `kappa_phi`, `kappa_psi`,
    number of MD steps (`nsteps`), and equilibration time
    (`measure_after_ps`).

  - `write_plumed_input(self, x)`  
    generates PLUMED input for a given `(φ, ψ)`; uses
    `MOLINFO STRUCTURE=simulations_essentials/diala.pdb`,
    defines φ/ψ torsions, constructs `sin/cos` variables, and writes
    `MOVINGRESTRAINT` blocks on them. The PLUMED file is stored as:
    ```text
    plumed/plumed_{phi:.3f}_{psi:.3f}.dat
    ```

  - `run_simulation(self, x)`  
    cleans temporary files, calls `write_plumed_input`, and runs:
    ```bash
    gmx mdrun -s simulations_essentials/md.tpr \
              -plumed plumed/plumed_{phi:.3f}_{psi:.3f}.dat \
              -nsteps {self.nsteps} \
              -x traj/traj_{phi:.3f}_{psi:.3f}.xtc
    ```
    The GROMACS binary is expected in `/usr/local/gromacs/bin`, as set in
    `run_command`. The resulting trajectory is saved in the `traj/`
    directory. Some large GROMACS output files (logs, checkpoints, `.trr`)
    are removed for convenience.

  - `get_force(self, x)`  
    reads the corresponding COLVAR file:
    ```text
    colvars/COLVAR_{phi_value:.3f}_{psi_value:.3f}
    ```
    discards data for times `t <= measure_after_ps`, to let the system equilibrate, computes mean `sin_phi, cos_phi, sin_psi, cos_psi`, compares with the umbrella
    centers, and returns the mean forces `[dF/dφ, dF/dψ]`.

- `run_adipep_short.py`  
  A shortened BUQ run that:

  - constructs an `Adipep` system,
  - configures `BQConfig` with a 2D Matern kernel, grid size, etc.,
  - initializes BUQ with a few starting points (e.g. `[-1.5, -1.5]`,
    `[0.0, 0.0]`, `[1.5, 1.5]`),
  - runs a limited number of BUQ queries (e.g. ~10),
  - reads `simulations_essentials/fes.dat` as a reference free energy
    surface and compares it to BUQ’s estimate (e.g. via RMSD),
  - optionally saves plots of the FES and the RMSD vs. number of queries.

- `simulations_essentials/`  
  Contains the MD input files needed for GROMACS+PLUMED:

  - `diala.pdb` / `diala.gro` – alanine dipeptide structure,
  - `md.tpr` – precompiled GROMACS run input,
  - `run.mdp` – GROMACS parameter file,
  - `fes.dat` – reference free energy surface on a φ/ψ grid
    (used for validation).

- `plumed/` and `colvars/`  
  A **small set** of PLUMED input and COLVAR files generated by
  running `run_adipep_short.py` once. These are provided so that PLUMED
  users can inspect real `plumed_*.dat` files and their corresponding
  COLVAR files without having to rerun the full BUQ workflow.

- `traj/`  
  Example GROMACS trajectories for each window. These are **not** needed
  by BUQ (which only uses COLVARs), but they are included as optional
  reference data. If disk space is a concern, they can be safely removed.

## Requirements

- **PLUMED:** 2.9.x  
  (tested with PLUMED 2.9.3)

- **MD engine:** GROMACS (e.g. 2023.2)  
  Used to run the biased simulations with PLUMED (`md.tpr`). The
  `run_command` helper assumes GROMACS is installed under
  `/usr/local/gromacs` and sets `PATH` and `LD_LIBRARY_PATH` accordingly;
  adjust this in `adipep_2d.py` if your installation is different.

- **Python:** 3.9+ with:

  - `numpy`
  - `matplotlib` (if you keep the plotting in `run_adipep_short.py`)
  - `buq` (the BUQ package, installed from the main BUQ repository)
  - any additional BUQ dependencies, as specified in `environment.yml`
    or the main `environment_buq.yml`.

A minimal environment can be created with, for example:

```bash
conda env create -f environment.yml
conda activate buq_adipep
```

To install BUQ itself, see the instructions in the main BUQ repository
(typically `pip install -e .` from the repo root).

## Testing PLUMED input

Pick one of the generated PLUMED files, e.g.:

```text
plumed/plumed_-1.500_-1.500.dat
```

From inside this directory (`plumed_nest_buq_adipep_2d`), run:

```bash
plumed driver --natoms 100000 --parse-only --kt 2.49 \
       --plumed plumed/plumed_-1.500_-1.500.dat
```

You should see PLUMED parse the file, list the `MOLINFO`, `TORSION`,
`MATHEVAL` and `MOVINGRESTRAINT` actions, the `PRINT` to `colvars`, and
finish with `Finished setup`.

## Running the BUQ + PLUMED example

Assuming you have GROMACS, PLUMED, BUQ, and the appropriate Python
environment:

```bash
conda activate buq_adipep

cd plumed_nest_buq_adipep_2d
python run_adipep_short.py
```

This will:

1. Initialize BUQ with a few starting (φ, ψ) points.
2. For each BUQ query:
   - generate a `plumed/plumed_{φ}_{ψ}.dat`,
   - run `gmx mdrun -s simulations_essentials/md.tpr -plumed ...`,
   - read the corresponding `colvars/COLVAR_{φ}_{ψ}`,
   - update the BUQ model and the estimated FES.
3. Compare BUQ’s FES to `simulations_essentials/fes.dat` and compute
   an RMSD as a function of the number of queries.
4. Optionally save plots of:
   - ground truth FES,
   - BUQ‑predicted FES,
   - their difference,
   - RMSD vs. queries.

You can reduce the number of BUQ queries in `run_adipep.py` if you
want a very quick run, or increase it to see convergence.

## Relation to the other alanine dipeptide PLUMED‑NEST egg

A separate PLUMED‑NEST egg (for example, `plumed_nest_diala_phi_psi`)
provides a **minimal PLUMED‑only** setup for alanine dipeptide with
static input files and a single example COLVAR.

This BUQ+PLUMED egg is complementary:

- The **minimal PLUMED egg** is suitable if you just want a φ/ψ PLUMED
  setup or a single umbrella window that has periodicity.
- The **BUQ+PLUMED egg** shows how a method (BUQ) can:
  - generate PLUMED inputs dynamically,
  - run biased simulations at many points,
  - use PLUMED outputs to reconstruct the full 2D free energy surface.
